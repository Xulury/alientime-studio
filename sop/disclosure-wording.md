# Disclosure wording

Enforced by the copy checks (Settings → Claims):

| Phrase | Allowed only when |
| --- | --- |
| "in hand" | custody = in hand |
| "full set" | box & papers = full set |
| "unworn", "brand new", "BNIB" | condition = unworn |
| "warranty" | a warranty fact is recorded |
| "service" | a service-history fact is recorded |
| "box and papers" | set includes box and papers |

- Every number in written copy must come from the confirmed facts (price, year, reference, case size…).
- No serial numbers, no "investment grade", no guaranteed appreciation.
- House terms, disclaimer and licence text are inserted by code exactly as written in Settings.
- Consigned pieces: copy says "held by our consignment partner; viewing by appointment".
