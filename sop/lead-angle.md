# Lead image

- The first gallery image is the lead (hero). Default: the best-scoring dial/front frame.
- Rotation for a lead angle is done by code (rotate the real photo), never by a model. When a frame has no room
  for the angle, an upright frame leads instead.
- Store frames are 2:3 portrait; squares 1:1; social 4:5. Platform sizes are derived from these.
